# Employee Layoffs Analysis

## Project Overview

This project analyzes a global employee layoffs dataset using Python to identify trends and patterns in workforce reductions. The analysis includes data cleaning, exploratory data analysis (EDA), descriptive statistics, and visualizations to better understand how factors such as industry, company stage, funding, location, and time relate to employee layoffs.

---

## Business Question

The primary business question addressed by this project is:

> **What company characteristics are associated with the largest layoffs, and are there identifiable patterns based on industry, company stage, funding raised, country, or time?**

Additional questions explored include:

- Which industries experienced the highest number of layoffs?
- Which countries reported the most layoffs?
- How have layoffs changed over time?
- Do companies with higher funding tend to have larger layoffs?
- Are there differences in layoffs based on company stage?

---

## Dataset

The dataset contains publicly reported global employee layoff information, including:

- Company
- Industry
- Country
- Location
- Date
- Total employees laid off
- Percentage laid off
- Company stage
- Funds raised (millions)
